## 实现

- 增加离线三角网格渲染器 `tools/scene-art/mesh.py`，使用 NumPy + Pillow。平滑顶点法线、深度缓冲、阴影贴图、透明接触阴影、长方形画框、可变姿态和明暗。与原有 SDF 渲染器并存，原有九页的素材和构图未修改。
- `tools/scene-art/pilot.py` 是本批的可重建模型和构图源。组团中的物体在同一个三维空间投影，使用同一光照及遮挡；运行时仍只加载一张适配当前方向的 WebP 图集，无新增运行时依赖。
- Docking：七根示意螺旋分成两组，周围有双层膜、配体和水分子。滚动时受体两组分开，两个配体向受体靠近。仅为装饰性示意，不是实际受体结构、分子式或对接结果。
- Awards：有内壁、杯沿、曲柄、基座和空白铭牌的紫色奖杯；无编号台座、奖牌、月桂、绶带和纸屑。奖牌随滚动升起，不表示已经获奖。
- Acknowledgements：带折痕与封口的信封、抽象卡片、七枝花、丝带礼盒和五枚抽象人物棋子。滚动时封口移开、卡片升起。棋子不对应真实人数。
- `sharedFrames` 明确保留受体分组、信封上下层的共享画框；修复图集打包器自动裁透明边导致的部件错位，并增加回归检查。未声明该字段的现有九页仍使用原打包行为。
- 允许新场景单独设置桌面／手机标题字号，原有场景保留默认字号。现有副标题位置、跳过入口、锚点留白和减少动态效果保持原逻辑。
- 内容审计登记两页为用户明确要求的空白阶段页面；最终提交审计仍报告正文缺失。未标记内容已审核。

## 复现

Python 环境需要 NumPy 和 Pillow；浏览器 QA 另需 Playwright 与 Chrome。模型重建不需要联网或生图服务。

```sh
python3 tools/scene-art/pilot.py
python3 tools/pack_scene_atlas.py model-docking awards acknowledgements
npm run verify
node --test tools/tests/scenes.test.mjs
npm run test:deployment
npm run test:theme
npm run test:captions
npm run test:media
node tools/scene-art/check-pilot.mjs
```

`pilot.py --layouts-only` 只重建构图；`--only <prop> ...` 仅重渲染指定模型。图集 URL 登记在 `src/data/scenes.ts`，本批保留本地资源以供评审，未上传、发布或推送。
