本文件根据「版本管理和Git」、第二轮内容调整、首页协作和查漏补缺任务中的用户要求整理。历史记录以实际仓库、构建产物及部署回执为准。

## 仓库与版本

- GitHub： https://github.com/CJerryR/NKU26-wiki 。源码使用版本分支；当前版本为 `v8.0`（package.json 为 8.0.0）。
- GitHub Pages：`gh-pages/<版本>/` 保留版本预览，`gh-pages/latest/` 更新为同一份构建。保留已有分支、旧版本目录、根页面及其他预览；正常追加提交，不强推。
- GitLab： https://gitlab.igem.org/2026/nku-china 。官方源码仍按现有要求直接提交 `main`，用 commit 记录版本；GitHub 同步不替代 GitLab 发布。
- iGEM 正式站： https://2026.igem.wiki/nku-china/ 。GitHub Pages 成功不代表正式站已经更新。正式站素材继续遵循官方托管要求。
- 当前 GitHub 源码以官方 GitLab 历史为基础，包含当前本地未提交修复。工作区历史备份、收到的原始文档、浏览器截图、依赖缓存及凭据不加入本次 GitHub 同步。

## 编辑与内容要求

- 内容唯一编辑源是 `content/wiki/*.json`；`src/content/pages/*.md` 由构建导出。保留 Tina 组件源码与当前组件目录，不恢复已被后续要求删除的占位正文。
- 中文 HP 总稿仅归档，不放到网页；英文按实际交稿排版。不得补写不存在的实验结果、公式、引用、图注、照片或人员贡献；缺失稿件保持真实缺失状态。
- 新版人物卡和 PPT 首页故事按后续要求保留，不恢复已经否决的旧卡片与旧首屏构图。25 位成员及对应贡献按真实稿件保留；没有照片时继续使用占位头像，不生成肖像。
- 液态玻璃关注透明与折射；目录和搜索面板采用共享效果，保留折射中心连续性修复。标题数字按用户要求置于左侧。
- 原始材料与每轮修改日志需本地备份。源码交给 Claude 重设计时，按用户当次要求提供源码包，不额外打包预览或依赖。
- 构建与内容技术审计必须通过；最终科学审核按实际状态记录，不能为通过审计伪造审核通过。
