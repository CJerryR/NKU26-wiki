## 第二轮（2026-09-24）：世界地图精简，「地图 → 田地 → 土壤」改为 three.js 3D

### 改动

- 世界地图区：删除章节标签 "02 Problem discovery"、导语段和 "Verified dataset import pending" 状态标签；丰度图例带 `data-world-legend hidden`，导入经核实的数据后才显示；统计改为 "US$173 billion / lost to plant-parasitic nematodes every year, worldwide (estimate)"，号召语缩短为一句。
- 世界地图动效：标题逐词浮现；点阵从中国向外波纹式显现；中国、案例标记、"China · Look closer" 依次淡入，标注轻微浮动；中国处两道声呐波纹。统计与号召语在聚光灯打开后随 0→173 计数一起出现（`NK.state.irisOpen` 与 `iris-pop` 事件，见 `home-core.js`）。
- 逐级放大：新增 `js/home-zoom3d.js`（three.js r149）。三个尺度各一个场景：中国三维板块与四大农区光斑 → 实例化玉米田（风摆、近处投影）→ 土壤剖面中的根系、团聚体与 J2；尺度之间用圆形「侦探镜头」转场。`home-zoom.js` 的 SVG 版本保留为降级（`NK.zoom2d`）。
- 3D 场景在页面 `load` 之后利用空闲时间分片构建，并预编译着色器、预上传大纹理；读者距该区域 1.5 屏以内时立即补完构建。

### 自动检查

- `python3 build.py` 成功；`python3 tools/audit_wiki_content.py --generated --generated-root public`：PASS；全部首页脚本通过 `node --check`。
- 桌面 1440×900 与移动 390×844（触屏，DPR 2）截图全程无控制台错误。截图脚本改为「等到条件满足再截」（聚光灯已绘制、对应层级已激活），不再用固定等待。

### 实测

- `home-zoom3d.js` 在加载时的同步耗时：约 250 ms → 29 ms（本机单核 CPU）；空闲分片每片 15–50 ms。
- 降级：禁用 WebGL 时使用 SVG 版；人为注入构建错误时记录错误并切换到 SVG 版（两条路径均实测）。
- 计数：聚光灯阶段数字保持 0 且统计不可见；开孔后只计数一次，单调增加到 173（桌面与移动均验证）。

### 本轮发现并修正的问题

- 数字在聚光灯下提前计数：`main.js` 会给页面上所有 `[data-count]` 元素播放计数动画，改用 `data-nk-count`；「等待开孔」的判断由读取遮罩透明度改为读取状态标记。
- 镜头转场半径是固定常数：竖屏上转场进行到一半圆圈就出了屏幕，桌面端在约 60% 进度就结束；改为按焦点到最远屏幕角计算。
- 土壤近景没有主体、根系过曝：重做构图——根系和土块避开镜头路径与视线，根毛只在成熟区，J2 围绕根尖分布并带信号颗粒，降低曝光，雾随镜头距离变化，竖屏单独取景。
- 其他：地图光斑被板块遮挡（改为贴地光斑）；俯冲偏离中心（先平移后俯冲）；高空雾过重（雾随高度变化）；田地帧在软件渲染下超时（减少实例、只让近处植株投影）；图例的 `hidden` 被 `display:grid` 覆盖；桌面端提示误写为 "Tap China"。

### 已知限制

- 所有截图和计时都在软件渲染下取得。真实 GPU（尤其手机）的帧率，以及首次调整画布尺寸的耗时（软件渲染下 `renderer.setSize()` 约 3.9 s），需要在目标设备上复核。
- 3D 场景是程序化的示意插画，不代表实测数据；农区光斑是示意位置。
- 丰度数据尚未导入；导入后图例自动显示。
