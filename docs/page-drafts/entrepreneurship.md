# Entrepreneurship

01 - Market

## A need hypothesis, not a market claim

Plant-parasitic nematodes create an important crop-protection problem in the literature, but broad agricultural burden does not prove demand for this particular detector. The reviewed stakeholder evidence does not identify a verified customer, payer, purchasing process, market size, acceptable price, or use frequency. The questionnaire stream is still unanalysed and cannot support a demand conclusion.

The first commercial question is therefore not how large the market is, but what decision a result would change. A candidate use case must specify the operator, sample, timing, comparator, consequence of a false positive or false negative, and the action available after a result. That workflow should be compared with existing morphology, molecular tests, isothermal methods, and field sampling practices before a value proposition is asserted.

02 - Model

## Questions a viable model must answer

### Value

A future offer would need to improve a real decision through earlier, easier, cheaper, or more informative evidence than an available comparator. None of those advantages has been measured. Analytical response, specificity, representative sampling, and result interpretation remain prerequisite validation gates.

### Operating model

Possible formats include a laboratory service, a kit used by trained operators, or a partnered workflow, but the evidence does not select among them. Each option changes quality control, biosafety, storage, training, waste handling, data responsibility, and regulatory questions. No revenue or cost model is yet supported.

### Route to use

A go-to-use path would require a technically relevant partner, a defined controlled environment, an operator workflow, and evidence that the result is actionable. A consultation note recommends that partnership requests articulate technical value, but no partner commitment, pilot, or route to market is documented.

03 - Plan

## Evidence gates before scale
- Stage 1

#### Validate the premise

Demonstrate receptor and reporter response under controlled conditions, quantify analytical limits, challenge specificity, and verify that the selected result changes a stakeholder decision.

- Stage 2

#### Define a bounded pilot

Only after the premise passes should a pilot specify sample custody, biosafety, operator training, controls, failure handling, data ownership, waste, and regulatory review. No field pilot is currently evidenced.

- Stage 3

#### Test reproducibility and delivery

Scaling would require batch consistency, storage and transport stability, supply-chain evidence, quality assurance, full cost accounting, support, and responsible end-of-life handling. These remain planned evaluation topics.

**Current documented status**

The project does not yet have a verified end-to-end detector, field performance, customer validation, market sizing, unit economics, regulatory conclusion, or business model. This page records the decisions and evidence required before any of those claims can be made.
