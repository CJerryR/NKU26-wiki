# Communication

01 - Channels

## What the current records support

### Teaching materials

### Public-channel status

The reviewed evidence does not document a verified press placement, publication, social-media campaign, or web-engagement result. Those channels should be added only when a dated artifact and its publication context can be checked.

02 - Strategy

## A traceable communication workflow

Our current evidence supports classroom-oriented science communication rather than a broad campaign. Future communication should begin with a defined audience and one learning or decision objective, then select a format that audience can access. Scientific content must distinguish established literature, the team's design hypothesis, planned validation, and measured results.

Each public item should retain a simple record: intended audience, approved content, publication date, channel, responsible owner, accessibility check, consent status for identifiable media, and the evaluation method selected before release. A page view or attendance number would describe exposure only; it would not by itself demonstrate understanding or impact.

For technical material, the signal source, recognition step, and observable readout provide a useful explanatory structure. For non-specialist material, comparisons and questions can reduce jargon, but uncertainty must remain visible. Fictional classroom outcomes must never be presented as evidence that the detector works.

03 - Reflection

## Evaluation remains planned

**Current documented status**

No verified questionnaire, pre/post comparison, feedback analysis, accessibility audit, or follow-up engagement is available for the documented activities. Future evaluation should define the question first, collect only necessary data with appropriate consent, separate exposure from learning, and report negative or inconclusive findings alongside positive ones.
