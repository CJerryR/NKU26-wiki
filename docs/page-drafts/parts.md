# Parts

01 — Overview

## A ledger, not a collection

This page tracks the genetic elements and construct work that appear in the team notebook and records what evidence does — and does not — exist for each. It is deliberately framed as a status ledger rather than a finished part collection: at this stage the source material names elements and documents cloning attempts, but it does not supply sequences, characterization data, or Registry-submission evidence.

**What has not been supplied**

No Registry part identifiers, sequence files, complete part maps, Registry-submission evidence, or characterization datasets were provided for any element below. No Registry submission or deposition evidence was supplied or verified, and no iGEM Registry part identifiers were supplied or verified. Element names describe intended cloning targets, not verified, sequence-defined parts.

04 — Verification

## How far verification actually goes

The strongest verification statement in the records is the preliminary PCR conclusion on 0607, where the author reported that eight CEN.PK2-1C ΔGal80 candidates were correct (RT negative, 5′/3′ positive). This came after explicit failed or inconclusive checks on 0603 and 0604. It is a colony / genomic PCR conclusion only: no gel photograph, band sizes, sequencing, or independent replicate accompanies it, so it is not proof of a sequence-confirmed genomic edit.

**Scope of the 0607 statement**

The 0607 conclusion concerns preliminary ΔGal80 edit verification only. It does not validate the GPR2-GFP fragment, GPR2 or GPR3 expression, any GPCR signalling, or a reporter part. The GPR2-GFP work has no reported result at any stage.

05 — Registry

## Before anything can be called a Part

No Registry submission or deposition evidence for anything on this page was supplied or verified. Before any element here could be presented as a contributed Part, the following would be required: confirmed sequences and part maps; a verified assembly; a Registry submission with an assigned identifier; and characterization data showing behaviour. Those steps are outstanding, which is why this page stays a draft ledger. The honest, dated record behind these elements is on the [ Notebook](../pages/notebook.html), with the associated bench workflows on [ Protocols](../pages/protocols.html); how this documentation could be reused is set out on the [ Contribution](../contribution/index.html) page.
