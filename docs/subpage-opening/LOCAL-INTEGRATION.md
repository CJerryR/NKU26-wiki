## 本地必要修复

- Claude checkpoint02/03的重复扁平化 `gpt/` 内容被拒绝，材料统一放在 `gpt/subpage-openings/`；原 `gpt/manifest.json` 16 张表保持不变。中文归档名修复为 UTF-8。
- 新素材独立导入，不使用旧的 handcut --all。导入保留透明度，按照单元格切图，并在相邻单元格间隙中线限制裁切，避免固定 padding 混入邻图。
- 从旧 Project CDN 映射中移除被改版的六张图集指向，改用新本地图集和内容 hash，避免新帧坐标读到旧素材。部署前可按常规素材上传流程替换为新 CDN 地址。
- 手机面包屑已改为相对布局，其旧的 top/left 残留偏移会挡住上方道具，改为正常边距。
- 矮横屏仍使用原来的左右分栏，标题宽度跟随左栏，避免长标题从左侧被裁掉。
- 离线导入脚本删除了未经请求的外部 API 生图入口。生图实际通过 Codex 内置 imagegen 完成，源图、提示词、风格板与 provenance 随成果保留。

## 科学与设计对应

| 页面 | 视觉叙事 | 内容边界 |
|---|---|---|
| HP Overview | 折叠地图展开为四条 HP 路径 | 总览入口，不将活动画成实验结论 |
| HP Investigation | 展馆、访谈、温室、采样沿路线展开 | 装饰性场景，不代表真实人数或精确实景 |
| HP Industry | 信封打开、邀请与演示资料出现，进入洽谈 | 交流与应用探索，不暗示量产、认证或签约 |
| Description | 两类感应信号、酵母试纸、田间初筛及后续确认 | 早筛设计概念，不替代专业检测 |
| Engineering | 四目标迭代站点，连接仍待推进的下一轮 | 不把计划中的集成与验证画成完成 |
| Contribution | 生物实验、计算建模、教育互动三类资源 | 表示可复用产出，不夸大验证程度 |

装饰性 AI 插画的来源见 AI-PROVENANCE.json。程序生成的虚线路径与合成帧属于排版元素。当前任务仅本地实现和验收，未发布。
