# NKU26 V10：手绘剪纸开场（基于 V9 / V8.7）

## 这一版做了什么
1. **道具换成首页的手剪纸画法**。V9 只是把 3D 明暗压成色阶，形体和"雨丝"纹理都不像首页。V10 按首页开场图的手法重新生成全部 91 个道具：
   剪刀剪出的折线外形、没有描边；每块是一种平涂纸色，叠上深浅不同的纸片；同方向的油画棒刮痕（橄榄绿上压赭黄）、干笔竖纹；
   土层是撒点加浅藕荷色石子；配色取自首页原图，提亮一档以便在夜空上看清。40 张图集的画框、构图、动画参数一个都没动。
2. **给 GPT 的完整包**（gpt/给GPT/，另有单独的 NKU26-给GPT.zip）：16 张底图分两批，加从首页团队原图裁出的风格参考和写死的提示词。
   上传、粘贴即可，不用改字。GPT 照着底图重画，位置和轮廓不变，所以质粒两半能合拢、四块拼图能咬合、盖子能盖回去。
3. **导入工具**：GPT 的图不用改名，放进 gpt/out/，运行 `python3 tools/scene-art/gpt_ingest.py`。
   自动认图（同一张画了多次用最新的；也可以命名为 05.png 指定）、去背景和阴影、放回原位、拆分质粒和拼图、生成镜像的另一块土和另一扇柜门，
   重建全部图集，并输出 gpt/out/_report.png 对照图。没画好的道具保留手剪风格版。有 OpenAI API key 时可以用 gpt_api.py 一条命令全部完成。
4. **开场和正文的衔接**：V9 的纸面从滚动 42% 就开始上升，盖住了道具展开的过程（比如 Description 土块分开露出根系）。
   现在正文纸面是开场后面一条全宽纸带，顶边是剪刀剪的折线，用负边距叠在钉住阶段的最后约 15%（手机约 11%），跟滚动同速升起，
   解除钉住后直接成为正文。纯 CSS，没有脚本；减少动态效果、禁用 JS 时只露一道剪纸边；暗色主题自动用深色纸。
5. 标题改成首页那样的奶油色、中等字重、柔和阴影；夜空改用首页已在 iGEM CDN 上的同一张图。
