# Tina 交互组件

在「Wiki 内页 → 选择页面 → 正文排版 → 添加」中选择新模块。三个模块均可不选文件先保存，页面显示占位提示。没有内置实验数据或假结构。

## 蛋白质结构（可旋转）

- 结构文件：通过媒体库选择 `.pdb`、`.cif` 或 `.mmcif`。
- 格式：通常留空自动判断；必要时手动指定 pdb / cif。
- 初始显示：丝带、球棍、原子球或分子表面。
- 主体颜色：十六进制，例如 `#8cae73`。
- 链：例如 `A`。只填链时突出显示这条链。
- 残基：例如 `42,57,100-105`。与链同时填写时只选这条链中的残基。
- 访客可以拖动、缩放、复位、旋转和全屏。结构查看器不预测或修改蛋白质。

## PDF 阅读器

选择 `.pdf`，设置标题、窗口高度及说明。页面直接嵌入 PDF，使用浏览器自带阅读器，不再加载自定义 PDF.js 工具栏。具体按钮、配色和功能由访问者的浏览器决定，Chrome、Edge、Safari 和手机可能不同。窗口下方保留「打开 PDF / 下载」链接，方便不支持内嵌阅读的设备打开原文件。Tina 中已保存的 PDF 模块自动使用这个方案，无需重新上传。

## HTML 阅读 / 交互演示

单文件 `.html` / `.htm` 可直接在媒体库上传。普通文档无需开启脚本；可信的交互页面开启「允许演示中的 JavaScript」。组件使用隔离 iframe，不允许读取父页面或 Tina 的存储。

多文件作品放在 `static/embeds/作品名/`，保留相对资源路径，然后将入口路径 `/embeds/作品名/index.html` 填入文件地址。ZIP 需先在本地解压，不能直接播放。脚本使用 ES modules、fetch 或依赖登录、存储的作品可能需要额外适配隔离环境；普通内嵌 CSS、经典脚本和图片可使用。外部网站也可能禁止嵌入。

## 通用设置

- 高度：300–1200 像素，默认 600。
- 标题用于工具栏和无障碍名称，说明显示在窗口下方。
- 本地保存只写本地文件；本轮组件需推送并发布后才会出现在云端后台。
- 页面仅在出现组件时加载对应阅读器，库文件来自 npm 并复制到本站，无需访问第三方 CDN。

## 维护

`npm run dev` / `npm run build` 前自动执行 `tools/prepare-viewers.mjs`，复制锁定版本的 3Dmol.js 和 PDF.js 及许可证到 `static/widgets/vendor/`，此目录不提交。模块源代码在 `static/widgets/`，Tina 配置在 `tina/config.ts`，内容转换在 `src/lib/media-blocks.mjs`。

首次安装执行 `npm install`。PDF 展示能力由浏览器决定；没有 WebGL 的浏览器无法显示蛋白质结构。
