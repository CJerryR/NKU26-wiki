# 各组组件选型展厅

本地临时地址：http://localhost:3000/component-showcase

原来的 `/component-library` 也展示同一份内容。项目启动方式仍为 `npm run dev`。

## 给各组的操作

1. 在左侧选择湿实验、干实验、HP 或设计；通用组件也会显示。
2. 点击编号跳到示例，直接操作切换、筛选、缩放等效果。
3. 喜欢的组件勾选“加入候选”。可用“只看已选”比较。
4. 到页面末尾填写组别、目标页面与要求，下载候选清单 TXT。
5. 各组保存自己的清单后，可以清空选择让下一组使用。

选择和备注仅保存在当前浏览器，没有上传服务。localhost 地址只能在运行服务的电脑访问。

## 覆盖范围

32 组示例覆盖 Tina 中全部 20 个模板，以及排版模板的全部 14 种类型。图表展示折线、柱状和散点三种配置；序列展示 DNA 和蛋白。原生 PDF 的具体功能由浏览器提供。

蛋白结构使用 RCSB PDB 的公开 1CRN 文件：
https://www.rcsb.org/structure/1CRN

PDF 使用 Mozilla PDF.js 官方展示文档，仍由原生浏览器呈现：
https://mozilla.github.io/pdf.js/web/viewer.html

其余演示内容为自行生成的图形、合成数据和虚构角色，不得视为项目成果。本页没有使用个人实验报告。

页面入口仅在本地编辑模式注入，不加入正式 Wiki 导航或普通静态构建。本轮未部署或推送。

源文件：`src/editor/toolkit-demo.astro`、`src/editor/showcase-data.mjs`。
