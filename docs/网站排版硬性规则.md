# 网站排版硬性规则

记录日期：2026-10-19

## 1. 执行范围

对各正文页面统一执行以下标题、编号、字体、间距、正文宽度、对齐及入口清理规则。按本文给出的数值修改公共样式，并清理造成冲突的页面局部样式。

## 2. 标题与编号

- 将所有英文标题统一改为句首大写（sentence case）：仅将第一个单词的首字母大写，其余单词按普通句子使用小写；专有名称、缩写和科学名称保留规范大小写。
- 将该大小写规则应用于页面标题、各级正文标题、对应目录标题及卡片等组件标题；句子形式的标题也执行同一规则。保留标题原意和标点，不为统一大小写而重写句子。
- 例如：`Project design & strategy`、`Silent killers underground: the urgent threat of plant-parasitic nematodes`。
- 保留 iGEM、pH、基因名等专有名称、缩写和科学名称的规范写法。
- 删除正文一级章节标题前的章节编号及其后的空格，只显示标题文字。例如：`Background`、`Project design & strategy`。
- 将正文二级标题按所在章节连续编号，格式为 `1.1`、`1.2`、`2.1` 等。
- 将左侧目录一级条目的编号设置为 `01`、`02`、`03` 等格式；缩进子目录，子目录不显示数字，可使用简短标题。
- 保留大号淡色装饰数字，与一级章节顺序对应。
- 为每处编号保留一个生成来源，消除重复编号；确保正文与目录的章节对应关系一致。
- 将各页面同一级正文标题的字号、字重及间距统一设置为下表数值。使用真实标题层级，不用普通段落加粗代替标题。

## 3. 字体、字号、字重与行高

将字体设置为 **Spline Sans**，按以下数值设置字号、字重、行高和字间距。以下 px 均为 CSS 像素。

### 桌面端及宽度大于 640px 的窗口

| 对象 | 字号 | 字重 | 行高 | 字间距 |
| --- | --- | --- | --- | --- |
| 正文一级章节标题（h2） | `clamp(28px, 2.3vw, 34px)` | `560` | `1.2` | `-0.012em` |
| 正文二级标题（h3） | `24px` | `560` | `1.3` | `-0.005em` |
| 普通正文 | `18px` | `380` | `1.65`（29.7px） | `0.005em` |

### 手机端：窗口宽度不超过 640px

| 对象 | 字号 | 字重 | 行高 | 字间距 |
| --- | --- | --- | --- | --- |
| 正文一级章节标题（h2） | `28px` | `560` | `1.2` | `-0.012em` |
| 正文二级标题（h3） | `21px` | `560` | `1.3` | `-0.005em` |
| 普通正文 | `17.5px` | `380` | `1.7`（29.75px） | `0.005em` |

## 4. 上下间距

| 项目 | 规则 | 桌面端对应值 |
| --- | --- | --- |
| 一级章节标题下边距 | `0.65em` | 18.2–22.1px |
| 二级标题上边距 | `1.65em` | 39.6px |
| 二级标题下边距 | `0.65em` | 15.6px |
| 普通正文段落间距 | `1.1em` | 19.8px |
| 相邻一级章节间距 | `clamp(56px, 5vw, 76px)` | 56–76px |

手机端使用上述相对单位，按对应字号换算：二级标题上边距 34.65px、下边距 13.65px，普通正文段落间距 19.25px。

相邻上下外边距按浏览器的 margin 折叠规则处理，不直接相加。

## 5. 正文宽度、左右边界与对齐

| 项目 | 硬性规则 |
| --- | --- |
| 左右边界 | 将正文左右边界与提示框、图表卡片的外边缘对齐 |
| 正文宽度 | 占正文栏 `100%`；与组件共用容器，容器上限 `65rem`，随窗口收缩 |
| 正文左右外边距 | `margin-inline: 0` |
| 正文左右内边距 | `padding-inline: 0`，不额外缩进 |
| 段落宽度限制 | 移除普通正文的 `max-width: 74ch` 限制，避免正文比组件窄 |
| 普通段落对齐 | `text-align: justify` |
| 段落末行 | `text-align-last: start`，末行自然左对齐 |
| 手机端页面留白 | 左右各 20px；正文与组件继续共用左右边界 |

将正文左边界对齐组件外框左边缘，将正文右边界对齐组件外框右边缘。保留提示框内部图标、内边距和图片内部留白。只对普通正文段落应用两端对齐，不将该对齐样式应用于标题、图注或表格。

## 6. 图片与科学排版

- 将图片容器设置为白底、圆角。
- 将图片等比缩放并居中显示，确保内容完整，不裁切、不拉伸，手机端不溢出。
- 将物种学名设置为斜体，将文献引用设置为上标，保留数据、单位和科研含义。
- 修改 `content/wiki/*.json` 内容源，再使用项目导出工具生成 Markdown，不只修改生成文件。

### 6.1 所有专业名词首次写全称，后续统一用缩写

- 对全站所有专业名词逐页、逐项检查和处理，覆盖物种、蛋白与受体、分子、技术方法、检测与建模方法等术语；不得仅处理下方两个示例或预设的少量关键词。
- 先建立覆盖全站的术语表，逐项记录全称、统一缩写、出现页面及每页首次出现位置，再按术语表修改正文。
- 按每个页面独立处理：专业名词在该页正文首次出现时写为“全称（缩写）”，后续出现统一使用该缩写。
- 首次定义后，不重复展开全称，不在同一页面混用多种缩写；区分单复数，保留缩写的规范大小写。
- 为相同术语在全站使用同一组全称和缩写，优先采用学科通用缩写。没有可确定通用缩写的术语按用户决定先保留全称，列入负责人确认清单，记录出现页面；不得漏检或擅自编造缩写。
- 下列 GPCR 和酿酒酵母仅演示格式，不构成术语处理范围清单。
- GPCR 首次写为 `G protein-coupled receptor (GPCR)`，后续写为 `GPCR`；复数语境使用 `GPCRs`。
- 酿酒酵母首次写为 *Saccharomyces cerevisiae* (*S.c*)，后续按本项目要求统一写为 *S.c*。全称必须拼写为 `Saccharomyces cerevisiae`；全称和此处的物种缩写均使用斜体。
- 只修改网页正文中的术语表达，保留文献原题、引用条目、文件名、代码标识符及实验材料精确编号。

## 7. 原始文件入口与重复翻页链接

### 7.1 仅在历史文档页保留历史原稿与下载入口

- 保留 `/source-archive/` 历史文档页、该页的历史原稿说明、文档列表及原始文件下载功能，确保页面和下载链接可用。
- 在 `/source-archive/` 之外的所有页面移除历史文档、历史原稿相关的文字、链接、按钮及入口组件，包括 `Historical Source Documents`、`Historical source documents`、`Original submission (.docx)`、历史原稿、原始文件下载及原稿查看等内容。
- 清理范围包含其他页面的正文、页眉、页脚、菜单和站内搜索结果；删除页脚等公共组件中的历史文档入口，不在其他页面展示历史文档页或其原稿的搜索条目。
- 同时删除入口附带的下载状态提示、说明文字及空容器，清理删除后留下的空段落和多余留白。
- 从内容源或入口生成组件中移除，不用 CSS 隐藏代替删除。
- 保留归档原始文件和历史文档页路由，不删除归档文件或科研数据；通过 `/source-archive/` 地址仍可直接访问历史文档页。
- 保留与正文原稿入口无关的实验数据下载、科研附件、文献引用及功能链接。

### 7.2 移除正文内重复的前后翻页超链接

- 删除正文中承担上一页、下一页或返回总览功能、与页面底部翻页按钮重复的独立导航段落，例如 `Back to HP Overview · Next: Education`。
- 同步删除该导航专用的分隔符、分隔线、空段落和多余留白。
- 保留页面底部统一的上一页、下一页导航按钮，并检查目标页面正确。
- 保留正文中具有内容语义的交叉引用、文献链接及章节导航，不按 `Back`、`Next` 等单词进行全局误删。
- 在 `content/wiki/*.json` 或对应生成组件中完成清理，再生成 Markdown。

## 8. 验收要求

- 逐页核对页面标题、各级正文标题、对应目录和组件标题均使用句首大写，专有名称及缩写大小写正确；核对正文标题层级、编号及对应目录。
- 核对同级标题和普通正文的字号、字重、行高及间距。
- 检查正文左右边界与组件外框一致；普通段落两端对齐，末行自然左对齐。
- 分别检查桌面端和手机端，确认图片保持比例且整页无水平溢出。
- 依据完整术语表逐页核对所有专业名词：有明确缩写的首次出现包含全称和缩写，后续统一使用缩写；没有可确定通用缩写的保留全称，交付负责人确认清单。检查全称拼写、大小写、单复数及物种斜体格式，不得只核验 GPCR 与酿酒酵母两个示例。
- 检查 `/source-archive/` 可直接访问，文档列表、说明及原始文件下载功能完整可用。
- 逐页检查历史文档页之外不再出现历史文档、历史原稿相关文字和入口，涵盖正文、公共页眉页脚、菜单及站内搜索结果；入口状态提示和空容器无残留。
- 逐页检查正文重复翻页链接已移除，页面底部统一翻页按钮可用，科研链接和数据下载正常。
- 提交改动清单、修改前后证据、测试结果和准确 commit SHA，交给本聊天复验。
- 按工作区规定使用任务目录、合并目录和发布目录，遵守归属与锁定流程；分别记录功能完成状态与发布状态。
