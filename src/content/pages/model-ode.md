## 3. ODE and the two-channel model | From signal response to target-density estimation {#ode-introduction toc="3. ODE and the two-channel model | From signal response to target-density estimation"}

After receptors recognize ascarosides, the detection result still requires two transformations: how intracellular signaling forms a readable color, and how color reflects target-nematode density. When southern root-knot nematodes and free-living nematodes coexist, an increase in a single color may come from an increase in the target or from a change in the background.

We established connected models around these two questions. ODE describes effective receptor input, the shared yeast pathway and color development, generating simulated responses for different mixed samples; the two-channel model uses paired colors to estimate target density when the background count is unknown. Building the models also progressively clarified the questions to be addressed: first ensure that pathway outputs retain input differences, then test whether those differences can distinguish target from background.

[Figure 3-1 placeholder | Serial calibration workflow of the ODE and two-channel models]

The upper part shows model construction from preset mixed samples through ODE-interface calibration to two-channel regression; the lower part shows the future application path for estimating Mi density from paired phone readings. Preset color targets are used to calibrate the ODE, while the subsequent regression uses color features converted from the actual ODE output.

This model assigned a position to every functional stage, but also exposed the difficulty of determining parameters. Final color is affected simultaneously by input sensitivity, signal amplification and pigment-production efficiency; a single color endpoint makes it difficult to determine these effects separately.

We therefore reconsidered the level of model detail: for the yeast signaling pathway, for which public quantitative models already exist, we reused the reaction structure and parameters; for the project-specific color-development stage, which still lacks independent observations, we retained an effective description and focused calibration on the input and output interfaces.

## 3.2 Connecting the published shared pathway to an effective color-development equation {#ode-core toc="3.2 Connecting the published shared pathway to an effective color-development equation"}

Referring to Supady Model B and the public materials of TU Delft 2012 iGEM, we reconstructed the G-protein cycle, scaffold module, Fus3 activation and feedback processes. Compared with the initial representation of signaling through two normalized variables, the new shared core retains the reaction relationships of the source model and records internal rates separately from project-adaptation parameters.

Conservation of total molecular quantities allows some states to reconstruct the remaining states. We retained five independent variables: G-protein heterotrimer $H$, activated Gα $A$, effective scaffold complex $Q$, activated Fus3 $F^*$ and activated feedback state $Z^*$. ## 3.3 Varying target and background independently to construct dual-sensor inputs {#ode-mixtures toc="3.3 Varying target and background independently to construct dual-sensor inputs"}

Applying the pathway to mixed soil samples first requires a clear account of how nematodes contribute input. The project uses southern root-knot nematodes, Meloidogyne incognita (Mi), as the target and Caenorhabditis elegans (Ce) as the background. Both may contribute ascr#3 and ascr#18, so we retain both ligands and vary the densities of the two nematodes independently.

To examine the effects of secretion composition and sensor preference on two-channel responses, we use the following simulation settings. Here, $q_3$ and $q_{18}$ denote per-nematode release rates of the corresponding ligands, and $w_3$ and $w_{18}$ denote the input weights of the same sensor for the two ligands.

| Simulation setting | Value |
| --- | --- |
| Combined release $q_3+q_{18}$ | 1 fmol per nematode per hour for both Mi and Ce |
| Release ratio $q_3:q_{18}$ | Mi 1:10; Ce 10:1 |
| Input weights $(w_3,w_{18})$ | P3: (2/3, 1/3); P18: (1/3, 2/3) |

The secretion-profile literature provides clues to compositional differences, while the exact ratios, shared release quantity and response weights in the table construct an ideal simulated scenario. Mi and Ce are currently represented at the J2 and L4 stages, respectively, with density defined per 100 cm³ of soil sample; collection time, effective volume and other conditions are fixed and recorded in the parameter configuration.

The concentration of each ligand is obtained by adding the release contributions of the two nematodes and converting according to collection time and effective volume. Holding the target fixed while increasing the background allows interference to be observed; holding the background fixed while increasing the target allows the target response to be examined. Independent variation of the two nematodes allows these two effects to be examined separately.

The two sensors use designs biased toward ascr#3 and ascr#18, respectively, corresponding to the candidate directions V368R and N84V. Docking provides design clues for this complementary preference; the specific weights need to be determined through pure-ligand gradient experiments. Cross-response is currently retained so that the two colors jointly reflect the mixed input.

This design also provides the basic form of measured calibration: vary target and background independently, record paired colors for the same sample, and include blanks and different background levels. Real data can progressively replace release assumptions, response weights and the phone-observation relationship.

## 3.4 Adjusting input and output interfaces using simulated color targets {#ode-calibration toc="3.4 Adjusting input and output interfaces using simulated color targets"}

In the initial simulations, different stimulus strengths produced similar endpoint colors. This made us realize that, beyond producing color, the pathway needed to be checked for retention of sufficient input differences.

We therefore fixed the shared pathway and prioritized adjustment of the effective input scale $K_L$ and pigment-production gain $a$. At the same stimulus, a larger $K_L$ corresponds to weaker effective drive, while $a$ controls the pigment amplitude that the downstream signal can produce. These two parameters were fitted separately for the two sensors, while $K$, $n$ and $\delta$ in the sixth equation remained fixed.

To cover low densities, tier boundaries and higher densities, we crossed six Mi densities with three Ce backgrounds to obtain 18 simulated color targets. Target values were determined by preset ligand contributions and a shared color scale, and a set of interface parameters approaching these endpoints was then sought.

The adjusted ODE followed the preset color changes over the overall range, but still responded below the linear targets in the weak-stimulus region. This advanced the question: we had obtained distinguishable color outputs, and next needed to test whether the retained low-end bias would hinder target-density estimation. Subsequent training therefore used the colors actually calculated by the ODE, allowing these deviations to enter the two-channel evaluation.

Preset color endpoints are used to calibrate the ODE; actual ODE outputs are used to train the two-channel model. This distinction gives the two steps different tasks and avoids replacing pathway-model calculations with a preset linear relationship.

To connect to the phone color-reading example, we then set the 8-hour total-pigment targets to 0.07–0.56 mg/mL indicaxanthin equivalent, adjusted basal pigment production, and uniformly scaled net-pigment amplitude. The pigment-production coefficients in the sixth equation were adjusted analytically, while the original $K_L$ remained unchanged, followed by checking through full ODE integration.

The actual endpoints of the two channels currently cover approximately 0.070–0.543 and 0.070–0.480 mg/mL, respectively; the endpoint-fit RMSE across 18 points is approximately 0.0097 mg/mL for both. This adjustment changes the output scale while retaining the original response shapes and relative deviations. The 0.07 mg/mL blank is the basal pigment production selected for this scenario; actual yeast background and induced production will be determined experimentally.

## 3.6 Using two colors to estimate target density {#ode-regression toc="3.6 Using two colors to estimate target density"}

After fixing the ODE and phone-conversion relationships, we varied Mi and Ce density combinations to generate 45 sets of paired readings. Each sample corresponds to a point in two-dimensional color space: the horizontal axis is the P3 reading $x_3$, and the vertical axis is the P18 reading $x_{18}$.

In this space, we can separately observe how the color combination changes when Mi is fixed and Ce increases, and when Ce is fixed and Mi increases. The different directions produced by these two changes provide a basis for using paired readings to distinguish target from background.

For example, a simulated sample with Mi = 40 and Ce = 80 produces sample-to-blank blue-channel ratios of approximately 0.854 and 0.879, and the model estimates Mi at approximately 39.72 J2/100 cm³. Ce density is not required as input to the two-channel model, and the predicted result subsequently enters the middle-risk tier according to the Eco example rules. This example connects the mixed sample, pathway color development, phone color features and target-density estimate.

We also examined samples near risk thresholds. Some small density deviations change the tier, so the interface checks the calibration range at the same time and indicates neighboring scenarios when the estimation interval crosses a threshold. The model output thus retains continuous density information and reflects the sensitivity of management decisions to where errors occur.

The above results come from noiseless simulations under the same ODE generator, showing internal estimation capability under the specified secretion profiles, sensor responses and color-reading relationships. Density predictions are essentially unchanged before and after the phone interface is added, showing that the new observation representation retains the original information.

At this point, the ODE and two-channel models have a clear division of tasks: the former calculates how mixed inputs produce two colors, while the latter uses these two colors to estimate Mi density. Code, parameter sources, frozen configurations and example data jointly support reproduction of this process and provide an interface for incorporating measured paired data. The Eco model in the next chapter further discusses how this density information affects management choices and expected income.
