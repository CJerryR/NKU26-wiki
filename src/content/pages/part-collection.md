## What the collection is for {#purpose toc="Purpose"}

This page will describe our parts as a single collection: the goal they share, the design logic that connects them, and the system function the set is meant to deliver. No collection has been assembled or verified yet, so nothing is claimed here. The current evidence for each element is on the [Parts](/parts/) page.

## How the parts fit together {#architecture toc="Architecture"}

An architecture figure will show which parts combine, which ones can be swapped for alternatives, and which combinations have been tested.

## Using the collection {#usage toc="Usage guide"}

For teams that want the whole set or a single part: the host, the conditions, the known limits and the common problems.

## Registry documentation {#registry toc="Registry"}

The Registry collection page and each part page carry the sequences, characterisation and usage notes. They are the formal record, and this page will link to them once they exist.
