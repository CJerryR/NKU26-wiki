# CLAUDE.md — NKU iGEM 2026 Wiki

Guidance for Claude (and humans) working in this repository.

## What this is
The competition wiki for **Nankai University's iGEM 2026 project** — a
synthetic-biology **biosensor for the early detection of two plant-parasitic
nematodes** (*Heterodera glycines*, soybean cyst; *Meloidogyne incognita*,
root-knot). Design theme: **"Subsurface"** — a soil-detective / field-notebook
aesthetic built around the team's magnifying-glass mascot and sonar-ring logo.
Target: **Best Wiki**.

## Golden rule — Best-Wiki compliance (do not break this)
iGEM **forbids loading any external resource at runtime** (no Google Fonts, no
CDN scripts/styles, no hot-linked images). Doing so risks **disqualification**.
Therefore:
- **All fonts are self-hosted** in `fonts/` (`@font-face` in `css/style.css`).
- **No `<script src>` or `<link href>` points off-site.** `js/main.js` is
  vanilla and dependency-free.
- All images are local (`img/`). Every page is **fully static** — no runtime
  `fetch`, so it works opened directly *and* on iGEM's GitLab Pages.
> If you add a library, vendor it into the repo. Never add a CDN tag.

## Architecture — build from source, don't hand-edit output
This wiki is **generated**. Never edit `index.html` or `pages/*.html` directly —
they are build artifacts and are overwritten.

```
_templates/base.html   skeleton: tokens {{TITLE}} {{DESC}} {{NAV}} {{FOOTER}} {{BODY}} {{P}}
_partials/nav.html     the ONE nav (mega-menu). {{P}} = path prefix
_partials/footer.html  the ONE footer.            {{P}} = path prefix
_content/*.html        page CONTENT only (front-matter + sections). EDIT THESE.
build.py               assembles everything → static index.html + pages/*.html
scaffold.py            (re)generates _content/*.html skeletons from a registry
css/style.css          the whole "Subsurface" design system (one file)
js/main.js             all interactions/animations (one file, vanilla)
fonts/ img/            self-hosted assets
docs/                  technical manual + development log
```

### Daily workflow
```bash
python3 build.py        # after editing _content / partials / templates / css / js
```
Open `index.html` in a browser to preview. Commit source **and** built output.

`scaffold.py` is a one-time generator; it will **not** overwrite hand-authored
pages listed in its `KEEP` set (currently `index`, `description`).

## Authoring a page (`_content/<name>.html`)
Front-matter is an HTML comment at the very top:
```html
<!--META
title: Design
crumbs: Project / Design
eyebrow: Project · The build
heading: Designing the <span class='ink-accent'>detector</span>
sub: One-line subtitle under the page title.
meta: Discipline=Synthetic biology | Reading=7 min | Status=Living document
-->
```
Then the body is a series of sections:
```html
<section id="brief" data-toc="Design brief">
  <p class="eyebrow sec-label">01 — Brief</p>
  <h2 class="section-title">What the sensor must do</h2>
  <div class="prose"><p>…</p></div>
</section>
```

### The floating TOC writes itself
The left-hand **floating outline island** (and its mobile counterpart) is
auto-generated by `build.py` from markers — you never maintain it by hand:
- `data-toc="Label"` on a **section that has an `id`** → top-level outline entry.
- `data-toc-sub="Label"` on any element with an `id` (e.g. an `<h3>`) → nested entry.
Add a marker, run `build.py`, the outline + scroll-spy update automatically.

`layout: home` in front-matter → full-bleed band layout, **no** TOC (used by
`index.html`). Anything else → page banner + floating TOC + content column.

## Design tokens (in `css/style.css :root`)
Paper/loam soil palette + iris-purple & amber accents.
- Surfaces: `--paper #f7f2e8`, `--paper-2`, `--loam #191222`, `--loam-2/3`
- Ink: `--ink`, `--ink-2/3` (on paper); `--cream`, `--cream-2/3` (on loam)
- Accents: `--iris #6e4fb8` (primary), `--iris-bright`, `--amber #e2a23c` (CTA), `--clay`
- Fonts: `--font-display` Fraunces · `--font-body` Spline Sans · `--font-mono` Space Mono
Use band classes `.band--paper` / `.band--paper-2` / `.band--loam`; components
`.card .stat .timeline .callout .figure .feature .refs .placeholder-tag`.
`.placeholder-tag` marks "team fills this in" spots — search for it before freeze.

## Animation system (`js/main.js`, all reduced-motion aware)
nav (hide-on-scroll, mobile drawer, mega) · scroll-progress bar · `.reveal*` &
`[data-stagger]` on-scroll reveals (IntersectionObserver) · `[data-count]`
number counters · **floating-TOC scroll-spy + moving rail + progress + collapse**
· hero load sequence · **hero detection-lens** (cursor-follow CSS mask reveals
hidden nematodes; auto-sweep on touch) · **swimming nematode** (rAF undulating
SVG ribbon) · `[data-parallax]` · mascot helper (scroll-to-top + tips).
`@media (prefers-reduced-motion: reduce)` and `@media print` are honored in CSS.

## Deploying to iGEM
Push the built `index.html`, `pages/`, `css/`, `js/`, `fonts/`, `img/` to the
team's **iGEM GitLab** repository (`https://gitlab.igem.org/2026/<team>`). Keep
the **relative** paths intact. Re-run `build.py` before every push.

## Before the Wiki Freeze — checklist
- [ ] Replace every `.placeholder-tag` with real content/figures/citations.
- [ ] Fill real data into pages that count for medals (Parts, Results,
      Engineering, Safety, Human Practices, Contribution, Attribution).
- [ ] Re-run `build.py`; confirm no `{{TOKENS}}` and no off-site `src/href`.
- [ ] Test with JavaScript on **and** off, and at mobile width.
- [ ] Verify it renders on the actual iGEM GitLab Pages host.

(开发日志) for the redesign history and rationale.
